Getting Started

Install on Samsung TV
in 4 steps

Requires Samsung Smart TV (Tizen 4.0+, 2016 or newer) in Developer Mode.

1
Enable Developer Mode on TV
On your Samsung remote: Settings → Support → About Smart TV
Quickly type 12345 on the remote → Enable Developer Mode → Enter your PC's local IP address → OK → TV reboots.
2
Connect via sdb
Open a terminal on your PC:
# sdb is bundled with Tizen Studio
sdb.exe connect <TV_IP>:26101
sdb.exe devices   # verify connected
3
Install davetv.wgt
tizen.bat install -n davetv.wgt -t <DEVICE_ID>
DEVICE_ID is shown by sdb.exe devices
4
Launch DaveTV
tizen.bat run -p DaveTV.DaveTV -t <DEVICE_ID>
Or find DaveTV under Apps → My Apps on the TV.
