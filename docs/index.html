Getting Started

Install on Samsung TV
in 4 steps

Requires Samsung Smart TV (Tizen 4.0+, 2016 or newer) and Tizen Studio on your PC.

1
Enable Developer Mode on TV
Remote → Settings → Support → About Smart TV → type 12345 → Enable Developer Mode → enter PC IP → OK → TV reboots.
2
Connect via sdb
# Connect (replace with your TV's IP address)
sdb.exe connect 192.168.1.XXX:26101
sdb.exe devices   # verify
3
Install davetv.wgt
tizen.bat install -n davetv.wgt -t <DEVICE_ID>
4
Launch DaveTV
tizen.bat run -p DaveTV.DaveTV -t <DEVICE_ID>
Or: TV Home → Apps → My Apps → DaveTV
